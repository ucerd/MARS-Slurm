# v1.1.0 — Instrumented research artifact

Companion to *Telemetry-Driven Resource-Aware Job Handling in Slurm GPU Clusters: An Open-Source Admission and Placement Framework*. Includes the shell-safe collector, exact saved drivers, manifests, all supplied instrumented data, historical frozen code and raw logs, storage diagnostics, and independent offline checks. The historical release is preserved for comparison, with its telemetry-provenance limitation disclosed. The release is an experimental research artifact, not a general production scheduler or evidence of universal throughput improvement. No journal DOI is asserted.

## Verification

The offline release check confirms the recorded server hashes, the six instrumented campaign summaries against the original per-job data, the saved drivers and manifests, and the replicated campaign aggregates. The archived raw GPU monitoring estimates are supplied for transparency; the manuscript's comparative energy/utilization analysis is limited to the replicated dataset. No new cluster execution is part of this packaging process.
